# Ring ORAM Implementation Plan

> **For the agent:** Use the `superpowers-executing-plans` skill to implement this plan task-by-task.

**Goal:** Add an in-process Ring ORAM client/server implementation with bucket metadata, position map, stash, XOR read-path aggregation, periodic eviction, and early reshuffle.

**Architecture:** Introduce a new `oram::ring_oram` module parallel to the existing `path_oram` and `onion_ring` modules. The server stores a binary tree of `RingBucket` objects, while the client implements the Ring ORAM protocol against that server and inherits `core::RAM`. The simulated server exposes an XOR path operation so `ReadPath` receives one aggregate payload and the client unmasks selected dummies locally.

**Tech Stack:** C++17, CMake, GoogleTest, existing `oram::core::RAM` API.
